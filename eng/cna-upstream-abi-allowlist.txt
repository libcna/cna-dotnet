# Reviewed upstream ABI differences, accepted by tools/coverage/baselinediff.py.
#
# An entry here is a difference someone looked at and decided this consumer does not care about.
# It is not a way to quieten the tool: every entry must match an actual difference, and one that
# stops matching fails the gate as stale rather than being ignored. An entry containing `*` is a
# glob over one reviewed family and is held to the same rule.
#
# The file is scoped to the transition currently being admitted -- the accepted generation in
# eng/cna-native-abi-policy.json against the one proposed to replace it -- because a finding is a
# statement about one step and matches nothing in the next.
#
# 2026-10-13, ABI 0.46.0 (CNA a3da0a5bb) -> 0.47.0 (CNA modules e67c54936), CNA
# plans/plan_modern_retirement.md MRT-008/MRT-012. 1419 consumed exports, 0 absent, 0 changed
# prototype; 3210 -> 3205 exports; no scalar or string difference. Every finding below belongs to the
# modern GPU layer CNA retired in this generation, and none reaches this binding.
#
# Not listed, because CNA's abi_baseline.json does not record shift-form flag constants and so this
# tool cannot see them: the generation also removed CNA_GRAPHICS_CAPABILITY_FLAG_COMPUTE_SHADERS and
# _INDIRECT_DRAW (bits 17-18) and CNA_RENDERER_FORMAT_USAGE_STORAGE_READ, _WRITE and _ATOMIC (bits
# 5-7), and CNA_RENDERER_FORMAT_USAGE_ALL lost those three bits (8191 -> 7967; the tool reports it as
# added, since 0.46.0's baseline did not record it). They were reviewed by hand. CNA.NET binds no
# capability flag and does not name the ALL mask; its two format-usage enums named the three storage
# bits and drop them in the same change, which tools/abi-verify confirms against the 0.47.0 headers.
#
# - The three compute work-group queries and the two indirect-argument initializers were removed with
#   the compute and indirect-draw paths. CNA.NET never imported any of them.

export cna_graphics_device_get_max_compute_work_group_invocations_ext was removed upstream (not consumed here)
export cna_graphics_device_get_max_compute_work_group_size_ext was removed upstream (not consumed here)
export cna_indirect_draw_arguments_init was removed upstream (not consumed here)
export cna_indirect_draw_indexed_arguments_init was removed upstream (not consumed here)
# - The two indirect-argument structures went with their initializers. No managed layout mirrors them.
struct CNA_IndirectDrawArguments was removed
struct CNA_IndirectDrawIndexedArguments was removed
# - Two graphics capabilities. CNA.NET named them as GraphicsCapability.ComputeShaders and
#   IndirectDraw (and CnaGraphicsCapability's twins); those members are removed in the same change,
